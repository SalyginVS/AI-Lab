- qwen3.8-27b-gsq-rco:iq3s-mtp-262k (9842917e7505) и iq3s-mtp-128k (939546f9e972); основной Q27 через pi-q27/medium по ADR-032.

## Клиент

Lenovo, Pi 1.0.3: сохраняются defaultProvider ailab-ollama, Q6 default, pi-q27. Добавлен только ailab-strata с отдельным model ID и SSH forward; Pi maxTokens 8192, настроенный contextWindow 32768. Dell резервный, Strata provider ещё не добавлен. Клиентские данные v44 вне MBIP не переобследовались.

## Допуск

Живой цикл Ollama → Strata → Ollama, API/SSE, reasoning, read tool + continuation, guards, Q6/Q27/embedding PASS. T-FAST F01/F02/F03/F05/F06/F09 PASS, F04 KNOWN OBS-10-01, F07 DRIFT 19 нечувствительных пакетов. Верхняя граница Strata, чистая сборка, reboot, полные T-MED/T-LONG и инженерное качество новой модели не проверены. Guard не покрывает умышленный запуск бинарников/изменение unit от root; выбор после дренирования делает владелец. Принятые Q6/Q27 роли относятся только к прежней поверхности.
