# Манифест комплекта

Статус: ACCEPTED RB-11, 2026-10-17. Назначение: связать компонент, источник, установку и проверку.
Порядок: выбрать строку components.tsv, проверить MEMBERSHIP и STATE, затем REBUILD_SOURCE, RUNBOOK, CONFIG_ARTIFACTS и TESTS. artifacts.tsv сохраняет захваченные fingerprints.

STATE и MEMBERSHIP сохраняют замороженное решение RB-03. Принятый этап документации не означает новую приёмку каждого runtime-компонента.
`private:` обозначает отдельно передаваемый приватный источник. `RB-xx:` обозначает evidence или тест этапа. `GAP:` обозначает открытый пробел. `external:` и URL обозначают внешний источник. Захваченные пути `RB-01/extract/` и `RB-02/extract/` относятся к приватным evidence, а не к файлам репозитория.
`NOT_COVERED:<причина>` явно фиксирует отсутствие процедуры или теста. `N/A:EXCLUDED` означает исключение компонента. `TBD:RB-12` допустим только для DOCS-VAULT, DOCS-USER-FILES и DOCS-OBSIDIAN-CONFIG. Обозначения не являются PASS.
Публичная проверка: `python3 -I Сборка/tests/repo/check_package.py --static-only` (K1–K7, K10; внешние архивы без локального файла не хешируются). Полный запуск, включая K8, K9 и внешний архив K5, требует параметров evidence.
При обслуживании передать `--start <последний принятый commit комплекта>`. При смене базы публичного сравнения указать `--base <принятый базовый commit>`. Изменение принятых артефактов после --start даёт FAIL намеренно; оно требует отдельной приёмки. Предпочтителен merge commit без squash/rebase, чтобы сохранить ссылки на коммиты программы.
