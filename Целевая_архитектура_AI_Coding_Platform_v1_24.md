## Boot и rollback
Цель: после boot power service (300 W), доступные mounts, tmpfiles root-owned pointer на Inkling, Strata enabled; Ollama/Gateway/RAG disabled только по boot policy. Ручной выбор runtime не меняет boot policy. Read-only postboot проверяет state, exact profile, context when loaded, loopback и power/thermal; READY_PENDING_FUNCTIONAL, не inference PASS. Функциональный postboot после согласованного reboot обязателен в контролируемом контуре. Unattended load не принят. Переход с проверенного v1.23 через [ADR-034](Решения/operational/ADR-034_MBIP05_Strata_Dual_Model_Default.md); транзакции server/client раздельны, private before/after journal и conflict-aware rollback, не автоматическое распределённое изменение.

## Приёмка
E01-P placement/CLI capability/planner PASS offline; FP8 On 4.125 GiB global KV estimate. Flash API long/agent PASS, Inkling E01 BLOCKED. E02-P четыре комбинации mock PASS и replay PASS; live NOT_RUN. E03-P/С offline integration и deployment preparation, не live acceptance. Решение владельца 27.11.2026: продолжительные испытания, сравнительные исследования контекстов, квантизаций и производительности исключены из текущего scope. Незавершённые long-context/agent/compaction испытания — NOT_RUN / DEFERRED; исторический прерванный Inkling E01 остаётся BLOCKED, не PASS. Только отдельно допущенные необходимые короткие функциональные проверки могут входить в дальнейшую эксплуатационную приёмку. G0, 300 W, guards, drain/release, rollback и требования безопасного postboot сохраняются; это не разрешение на нагрузку или внедрение. Исторические L1–L3 long gates и исходный E03-C deployment path отложены, не являются критическим путём текущего этапа. G0 остаётся блокером переходов и генерации; после отдельного допуска только необходимые короткие функциональные проверки, F07 disposition и review. Будущее внедрение требует отдельного согласования и валидации обновлённого deployment contract; не обходить текущие gates. Документационная публикация выполняется отдельно и не закрывает live acceptance. Не повторять принятый Flash API long/agent; не снижать target 262144 или SQ-20 без отдельного обоснованного решения.
