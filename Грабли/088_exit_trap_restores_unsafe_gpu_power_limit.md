# 088 — EXIT trap временного root-контроллера возвращал опасные 420 Вт

**Симптом.** При испытании 350 Вт root-контроллер досрочно завершился. EXIT trap восстановил 420 Вт, нарушение обнаружено примерно через 39 секунд. Испытание остановлено и классифицировано `INVALID`.

**Причина риска.** Обработчик выхода менял аппаратный лимит даже после аварийного завершения управляющего процесса. При 420 Вт ранее зафиксирован `HW Thermal Slowdown` на длительной полной нагрузке. Причина самого выхода контроллера UNKNOWN.

**Исправление.** В рабочем контуре вместо временного root-контроллера используется постоянная служба `ailab-gpu-power.service`: 300 Вт, проверка значения, запуск до Ollama. Не делать cleanup, восстанавливающий 420 Вт. 350 Вт не объявлять безопасными на основании INVALID; владелец отменил повтор.

**Проверка.** F09 требует `power.limit=300`, служба `active (exited)` и `enabled`. [Установка](../Сборка/10_Сервер_ОС_и_драйвер.md), [откат только с решением владельца](../Сборка/80_Восстановление_и_апгрейд.md), [паспорт v41](../Паспорт_лаборатории_v41.md). Приватные журналы в Git не публикуются.
