# 093 — требование написать тест без явного разрешённого места

## Симптом
Протокол требовал писать регрессионные тесты, но модель размещала их по привычке: `test/search.test.tsx` либо `task-handoff.test.ts`. В E1B это приводило к `protected_files=FAIL` и `allowed_paths=FAIL` при высоких функциональных оценках.

## Причина
Постановка не давала однозначного примера имени файла и пути, совместимого с allowlist. Протокол «добавь тест» мог противоречить практическому разрешённому набору путей.

## Решение
В каждом задании отдельно указывать допустимый glob, конкретные разрешённые примеры и запрещённые каталоги, требовать `git diff` перед сдачей. Примеры: для C — только `src/search/**`; для B — `packages/server/src/**/task-handoff.<часть>.test.ts`. Правила не меняют DESIGN, а снимают неоднозначность.
