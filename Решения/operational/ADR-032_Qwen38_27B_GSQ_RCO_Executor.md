# ADR-032: Qwen3.8-27B GSQ-RCO — локальный исполнитель готового DESIGN

## Контекст

Программа Q27 (E0, E1A, E1B, E2, E1C) исследовала Qwen3.8-27B IQ3_S + MTP на RTX 3090 и в Pi. Самостоятельный выбор недоопределённых требований, место тестов и пограничные случаи создавали дефекты. Явные дополнения к DESIGN дали функциональные оценки 49/49 (React) и 55/55 после исключения дефекта оценщика B007 (сервер/PostgreSQL), но прогоны подробной доработки E1C были INVALID из-за ошибки harness; их S2 не установлен. Решение приёмщика E2: **ACCEPTED_WITH_LIMITATIONS**.

## Решение

Развернуть Q27 как **локального исполнителя по готовому DESIGN**, не как архитектора и не как приёмщика. Поручения составлять по [правилам](../../Модели/qwen3.8-27b-gsq-rco_как_ставить_задачи.md): явное место и шаблон имени теста, исчерпывающие пограничные случаи с ожидаемыми кодами и сообщениями, не менять работающий код без воспроизводимого падающего теста.

Конфигурация Pi: thinking **medium**, `maxTokens=262144`, `contextWindow=262144`, temperature 1.0, top_p 0.95, top_k 20, min_p 0, presence_penalty 0, repetition_penalty 1.0. На сервере одна большая модель одновременно, постоянный лимит RTX 3090 **300 Вт**. Внешняя приёмка и проверка допустимых путей обязательны.

Доступ на Dell: `pi-q27`. Модель **не** становится Pi defaultModel. Основной принятый исполнитель Q6 сохраняется по [ADR-031](../ADR-031_Qwen38_Q6_Pi_Complex_Bounded_Executor_Deployment_Contract.md).

## Альтернативы

- Дать модели свободно проектировать — отклонено: соответствие требованиям DESIGN без ясных границ не гарантировано.
- Использовать `low` или `xhigh` по умолчанию — отклонено по E0/E1C; `medium` — принятый баланс.
- Заменить Q6 по умолчанию — не входит в решение, совместимость текущих задач Q6 сохраняется.

## Следствия и откат

Нужно поддерживать карточку модели, образец Pi конфигурации, внешний acceptance и инструкции для владельца. Для отката удалить только запись Q27 из пользовательского `models.json` и `~/.local/bin/pi-q27` (с сохранением резервной копии и Q6), не изменяя серверные теги и лимит мощности.
