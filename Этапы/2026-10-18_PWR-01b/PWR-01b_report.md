# PWR-01b: документирование постоянного ограничения мощности GPU

**Дата:** 2026-10-18. **Ветка:** `rebuild/pwr01b` от `origin/main`, старт `9a10a14`. **Итог исполнителя:** **READY_FOR_REVIEW**, с явно незакрытой live-проверкой F09 и ожидаемым K5 FAIL, требующим решения приёмщика. Merge не выполнялся.

## Основание и принятое решение

RTX 3090 работает с постоянным лимитом **300 Вт** через `ailab-gpu-power.service` (`Type=oneshot`, `RemainAfterExit=yes`, `-pm 1`, `-pl 300`, проверка 300 Вт, `Before=ollama.service`). По принятому испытанию 420 Вт приводили к `HW Thermal Slowdown` приблизительно через 5,5 минуты (ядро 82 °C, вентиляторы 100%, 365–378 Вт). При 300 Вт 30 минут PASS (80 °C максимум, вентиляторы до 69%). 350 Вт INVALID: root-контроллер завершился и EXIT trap возвратил 420 Вт; решение владельца: не повторять. Это не доказательство приемлемости 350 Вт.

После изменения платформы первоначальный T-MED дал M08 FAIL (UNKNOWN), а полный официальный повтор дал **10 PASS / 2 INFO**, M08 PASS. Первоначальная неудача сохранена.

## Незакрытый acceptance gate: живой T-FAST

Новый collector с `baseline.live-2026-10-18.json` **не удалось выполнить на живом сервере**: доступ с Dell по SSH в доступном неинтерактивном контуре не подтвердился (key authentication denied / timeout). Пароль в отчёты не записывался. Поэтому **свежий read-only F09 имеет статус NOT_EXECUTED**, а не PASS. Принятый более ранний PWR-01 evidence подтверждает установленную службу, 300 Вт после reboot и отсутствие дрейфа в период наблюдения, но **не заменяет** запуск нового F09.

После восстановления авторизованной SSH-сессии нужно исполнить только `t_fast_server.sh` через `ssh -T ... 'bash -s'` с протоколом вне Git и оценить его через `evaluate.py --baseline baseline.live-2026-10-18.json`. Для F09 требуется PASS; остальные F-критерии оценивать по действующим baseline и известным ограничениям. Не перезапускать сервисы, не менять лимит, не запускать T-MED без отдельного разрешения.

**Review-gates:** проверка diff и неизменности приватных границ; приёмка точечного изменения принятого `evaluate.py` (K5); read-only live T-FAST с новым baseline. До этих проверок это поставка на review, **не ACCEPTED**.
