# ADR-033: два inference backend с ручным выбором режима

## Контекст
Владелец расширяет возможности локальной платформы, не заменяет принятый Ollama и не заказывает сравнение моделей. На единственной RTX 3090 24 GiB с лимитом 300 W тяжёлые модели не должны работать одновременно. MBIP-01 показал неподтверждённость импорта Q6; MBIP-02 показал отказ штатной подготовки bartowski Q6_K. Q27 dense qwen35 не поддерживается штатным импортом Strata 0.2.22. Владелец отдельно согласовал один поддерживаемый GGUF Qwen3.6.

## Решение владельца
Ollama — основной режим при загрузке; Strata — альтернативный режим по явной команде владельца после дренирования запросов. Оба используют свои endpoint и профили Pi; никакого общего прокси, диспетчера запросов, автоматической маршрутизации или переноса Ollama с 11434. Существующий Gateway остаётся Ollama-зависимым. В Strata mode Ollama, Gateway и RAG временно недоступны; Docker MCP и SearXNG MCP не переключаются.

Переключение через mbip-backend с локальным lock, проверкой простоя, ресурсов, readiness и четырьмя ExecCondition guard. Strata static, отдельный пользователь, loopback HTTP и SSH forward; ключ API не требуется, граница удалённого доступа SSH. Оператор обязан предотвратить новые запросы при смене режима; защита не является полной блокировкой параллельных прямых стартов или намеренного обхода root.

## Альтернативы
Общий прокси/арбитр и автоматическое переключение отклонены владельцем. Изменение accepted Q6/Q27, обход проверок GGUF и повторные исследования качества исключены.
