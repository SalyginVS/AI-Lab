# Ограничение T4 manylinux2014

Фактическая команда T4 завершилась кодом 1 для RAG на numpy==2.4.4. Для остальных трёх сервисов код 0.
Все версии RAG сохранены. Нативная загрузка и установка по тому же lock прошли; pip check: 0.
Ниже полный список пакетов RAG, для которых метаданные PyPI не содержат wheel под указанный platform tag.

| Пакет | Версия | Доступные теги подходящих Linux wheel |
|---|---|---|
| numpy | 2.4.4 | cp312-cp312-manylinux_2_27_x86_64, cp312-cp312-manylinux_2_28_x86_64 |
| onnxruntime | 1.24.4 | cp312-cp312-manylinux_2_27_x86_64, cp312-cp312-manylinux_2_28_x86_64 |
