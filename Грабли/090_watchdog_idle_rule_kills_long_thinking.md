# 090 — отсутствие tool call не доказывает зацикливание модели

## Симптом
F-2 (A-1b) завершён как `INVALID` обвязки: watchdog убил исполнение после 30 минут без вызовов инструментов.

## Причина
Правило «нет tool call 30 минут = зацикливание» неверно для Q27: длинное непрерывное рассуждение нормально и не обязательно свидетельствует об отсутствии прогресса.

## Решение
Разделять продолжительную генерацию reasoning и настоящий повторяющийся цикл по содержимому. Использовать подтверждённый reasoning watchdog и верхнюю границу 8 часов на прогон; не заменять анализ телеметрии таймером отсутствия tool call.
