## Исключённые попытки F-1…F-3

| Попытка | Причина | Статус |
|---|---|---|
| F-1 / A-1 | `maxTokens=32768`, `stopReason=length` после примерно 125k символов thinking, без готового кода | `CONFIG_LIMITED_32K`, 26/81 — только диагностическая метрика |
| F-2 / A-1b | Watchdog ошибочно принял 30 минут последовательного рассуждения без tool call за цикл | `INVALID` (wrapper), не доказан model loop |
| F-3 / первая попытка A-1c | Сбой SSH ControlMaster → устаревший NVIDIA-SMI → ложный GPU fault | `INVALID` (wrapper), GPU не была повреждена |

Ни один F-1…F-3 не входит в оценки. Разбор причин: [089](../../Грабли/089_pi_maxtokens_32k_xhigh_truncates_thinking.md), [090](../../Грабли/090_watchdog_idle_rule_kills_long_thinking.md), [091](../../Грабли/091_gpu_monitor_over_ssh_false_gpu_fault.md).

## Принятые ограничения

E2 `ACCEPTED_WITH_LIMITATIONS` относится к конкретной связке Dell/Pi/Ollama/RTX 3090. Запрещено подменять критические ворота процентом функциональных проверок. Модель способна писать и запускать тесты, но отчёт `all gates green` однажды противоречил внешней проверке. Нужны явные требования к местоположению тестов и пограничным случаям, `medium`, `maxTokens=262144`, GPU 300 Вт и **независимая приёмка**.

Секретные эталоны, скрытые проверки и ключи в Git не публикуются. Полные evidence и JSONL сохранены только на Dell.
