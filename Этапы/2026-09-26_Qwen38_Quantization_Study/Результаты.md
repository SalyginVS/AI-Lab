# Qwen3.8 Flash-Next — Q5 / Q6 / Q8 quantization study

**Дата:** 2026-09-26
**Стенд:** RTX 3090 24 GiB + ~62 GiB RAM
**Executor surface:** VS Code + Pi
**Context target:** 262144
**Статус:** CLOSED

## Цель

Проверить, даёт ли повышение quantization Q5 → Q6 → Q8
воспроизводимое практическое преимущество на реальных bounded-executor
задачах, достаточное для дополнительной нагрузки на single RTX 3090.

## Проверенные модели

- Q5: `qwen3.8-flash-next:125b-a6b-q5_K_M-ab-262k`
- Q6: `qwen3.8-flash-next:125b-a6b-q6_K-ab-262k`
- Q8: `qwen3.8-flash-next:125b-a6b-q8_0-ab-262k`

Все тестировались с context window 262144.

## Empirical results

### RevisionTrace

Один frozen synthetic world:

- Q5: 1/6 full-correct
- Q6: 4/6 full-correct

Сильный положительный Q6-сигнал, но только на одном world.

### Simple IDE resolver

Hidden evaluator:

- Q5: 24/24
- Q6: 24/24

Ceiling effect; различий не выявлено.

### VPE-Next

- Q5 run1: 98/100
- Q5 run2: 98/100
- Q6 run1: 100/100
- Q6 run2: 98/100
- Q8 run1: 98/100

Q8 воспроизвела те же два G03 defect:

- `G03_snapshot_records_immutable_view`
- `G03_snapshot_records_repeat_copy`

Q6 run2 воспроизвела тот же defect.
Единственный Q6 100/100 не воспроизвёлся повторно.

## Q8 runtime admission

Q8 успешно загрузилась в Ollama:

- quantization: Q8_0
- runtime context: 262144
- short smoke: PASS
- expected answer: `Q8_RUNTIME_OK:703`
- short-run decode: ~3.85 tok/s
- GPU memory used: ~22.7 GiB
- minimum MemAvailable during short smoke: ~59.7 GiB
- swap pressure during short smoke: negligible

Короткий smoke подтвердил техническую загрузку, но не дал
основания считать Q8 эксплуатационно выгоднее Q5.

## Decision

Повышение Q5 → Q6/Q8 не дало воспроизводимого практического
качества, достаточного для дополнительной нагрузки на RTX 3090.

Принято:

- Q5 остаётся primary bounded executor.
- Q6 lane закрывается.
- Q8 lane закрывается.
- дальнейший quantization chase прекращается;
- следующий прирост качества искать в harness / contract /
  model generation, а не в Q8 этой модели.
