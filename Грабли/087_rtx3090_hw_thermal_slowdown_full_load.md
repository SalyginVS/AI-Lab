# 087 — RTX 3090: длительная полная нагрузка при 420 Вт вызывает HW Thermal Slowdown

**Симптом.** При 420 Вт приблизительно через 5,5 минуты полной GPU-нагрузки зафиксирован `HW Thermal Slowdown`. Температура ядра достигала 82 °C, вентиляторы 100%, потребление 365–378 Вт.

**Принятое измерение.** С лимитом 300 Вт тот же 30-минутный класс нагрузки завершился PASS: ядро до 80 °C, вентиляторы до 69%, прирост счётчиков HW Thermal Slowdown и HW Power Braking равен нулю.

**Вывод.** 420 Вт не являются подтверждённо устойчивым длительным режимом для конкретной RTX 3090. Температура ядра не описывает весь тепловой режим GPU; первопричина внутри узлов охлаждения не установлена. 350 Вт не валидированы.

**Предотвращение.** Постоянные 300 Вт через `ailab-gpu-power.service`, F09 после загрузки; нельзя автоматически снимать лимит при выходе тестового процесса.
