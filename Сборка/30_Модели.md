## Переменные и правила исполнения

Укажите абсолютные каталоги будущей чистой площадки.
${LAB_MODELS_DIR} хранит полученные исходники и Modelfile.
${LAB_OLLAMA_MODELS} является каталогом хранилища, с которым уже настроен daemon Ollama.
${LAB_OLLAMA_URL} является URL этого daemon. Его установку и настройку покрывает RB-06.
${LAB_EVIDENCE_DIR} указывает на каталог evidence программы.
Пути не должны содержать переводы строк или кавычки.
Не направляйте команды импорта на действующую лабораторию.

```bash
set -euo pipefail
: "${LAB_MODELS_DIR:?Set absolute model download directory}"
: "${LAB_OLLAMA_MODELS:?Set clean daemon model-store directory}"
: "${LAB_OLLAMA_URL:?Set clean Ollama daemon URL}"
: "${LAB_EVIDENCE_DIR:?Set evidence directory}"
export LAB_MODELS_DIR LAB_OLLAMA_MODELS LAB_OLLAMA_URL LAB_EVIDENCE_DIR
export OLLAMA_HOST="${LAB_OLLAMA_URL}"
mkdir -p "${LAB_MODELS_DIR}/blobs"
df -B1 "${LAB_MODELS_DIR}" "${LAB_OLLAMA_MODELS}"
```

Команды создают каталоги только на будущей площадке. Если свободного места меньше указанного ниже, получение не начинать. При ошибке HTTP, авторизации, лицензии или SHA256 остановиться; другое квантование автоматически не выбирать.
