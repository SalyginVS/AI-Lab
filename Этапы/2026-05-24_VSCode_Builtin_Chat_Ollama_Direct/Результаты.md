# Результаты: VS Code built-in Chat/Copilot direct Ollama operational signal

Дата: 2026-05-24
Контур: AI Lab RTX3090
Статус: operational signal captured
Documentation source of truth: `/home/vladimir/llm/AI-Lab` + GitHub

## 1. Контекст

После обновления Ollama до `0.24.0` был зафиксирован отдельный эксплуатационный сигнал: встроенный Chat/Copilot в VS Code был настроен на прямую работу с Ollama и использовался вечером в agent mode.

Это не является полноценным benchmark, но является сильным operational signal из реальной работы.

## 2. Наблюдения пользователя

Факты от оператора лаборатории:

- VS Code built-in Chat/Copilot, настроенный напрямую на Ollama, показал превосходный практический результат.
- По сравнению с прежними контурами наблюдались:
  - выше стабильность;
  - выше скорость;
  - выше предсказуемость применения инструментов в agent mode.
- Ранее забракованная модель `GLM4.7` в этом execution surface показала диаметрально лучший результат.
- Следовательно, предыдущая негативная оценка `GLM4.7` не должна считаться окончательной model-level rejection.

## 3. Архитектурный вывод

Качество агентского поведения нельзя оценивать только по модели.

Наблюдаемое качество зависит от связки:

```text
observed_agent_quality =
  model_capability
  × execution_surface
  × context_packaging
  × tool_protocol
  × apply_mechanism
  × latency_profile
  × permission_boundary
```

Следствие:

- verdict по модели должен включать поле `evaluated_surface`;
- старые оценки моделей без surface context считаются ограниченными;
- GLM4.7 переводится в статус `revalidation_required`, а не `rejected`;
- VS Code built-in Chat/Copilot direct Ollama становится candidate daily-agent lane.

## 4. Pi / OpenCode community signal

Факты от пользователя:

- В сообществе пользователя Pi сейчас является одним из двух основных agent tooling направлений.
- Второй основной инструмент - OpenCode.
- Лидеры сообщества ищут универсальный подход, который берёт лучшее у лидеров рынка, но совместим не только с proprietary models.

Интерпретация для AI Lab:

- Pi нельзя игнорировать как marginal tool.
- Pi должен быть добавлен в evaluation backlog рядом с OpenCode.
- Ключевой критерий оценки - не популярность, а способность дать controlled, model-agnostic, local-compatible agent harness.

  Role: watchlist / optional experiment after Ollama 0.24.0
