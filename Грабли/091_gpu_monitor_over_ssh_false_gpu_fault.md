# 091 — потеря SSH телеметрии не равна GPU fault

## Симптом
В исключённой попытке F-3 (первый A-1c) ошибка SSH ControlMaster привела к устаревшим данным NVIDIA-SMI и классификации `INVALID` как подозрения на GPU fault.

## Причина
Монитор на Dell принял неполученную свежую телеметрию через SSH за аппаратную неисправность видеокарты.

## Решение
Записывать GPU-телеметрию на самом сервере; отдельно контролировать доступность транспорта, свежесть показаний и состояние железа. Отказ связи помечать transport/monitor INVALID, не приписывать GPU failure без подтверждения. Сохранять постоянный power limit 300 Вт.

## Проверка
Серверный монитор и PWR-01 в E1B; [паспорт v41](../Паспорт_лаборатории_v41.md), [результаты Q27](../Этапы/2026-10-21_Q27/Q27_результаты.md).
