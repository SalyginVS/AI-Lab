# 092 — grader проверяет внутренности эталона вместо DESIGN

## Симптом
Проверка B007 требовала точного `HANDOFF_CONFLICT`, хотя DESIGN B5 задавал ограничение `recipient != actor`, но не этот конкретный код ответа. Из-за этого корректная альтернативная реализация получала неверный отрицательный результат.

## Причина
Оценщик был связан с деталями реализации эталона, отсутствовавшими в опубликованном интерфейсном контракте.

## Решение
Сопоставлять каждую ожидаемую проверку с конкретным требованием DESIGN. При несоответствии отмечать `TEST_DEFECT`, фиксировать решение приёмщика, не подменять эталон и не подгонять модель. B007 исключён из S1 B4-1b/B4-2; исходные JSON и evaluator остались неизменными.
