# T-LONG: процедура, запуск не выполнен

Статус: PROCEDURE_ONLY. Назначение: проверить извлечение маркеров из начала, середины и конца длинного контекста Q6.
Использование: только после отдельного разрешения владельца. RB-10 такого разрешения не содержит.

1. Сначала выполнить T-FAST и короткую проверку Q6. При FAIL инвариантов или REVALIDATE определить применимость ADR-031 с владельцем.
2. На Dell создать fixture во временном каталоге командой `python3 -I generate.py --output /absolute/temp/fixture.json`. Сравнить SHA256 с `fixture.sha256`. Повторная генерация должна дать те же байты.
3. Записать время UTC, digest Q6 и `/api/ps`. Передать JSON через POST `/v1/chat/completions` с `Content-Type: application/json`. Пример после разрешения: `curl --connect-timeout 15 --max-time 7200 --fail-with-body --silent --show-error -H 'Content-Type: application/json' --data-binary @/absolute/temp/fixture.json "$LAB_OLLAMA_URL/v1/chat/completions" > /absolute/evidence/t_long_response.json`. Файлы создаются на Dell. Серверные файлы не создаются.
4. Сохранить HTTP status, время, весь ответ, usage и повторный `/api/ps`. Установить фактический размер по `usage.prompt_tokens`. Генератор содержит 224700 повторов ` a`; размер около 225000 токенов является допущением о tokenizer, не измеренным фактом. Условия размерной приёмки: 220000–230000 prompt tokens, сумма prompt + 1024 ниже 262144. Вне диапазона это размерная непригодность fixture. Не менять ожидаемые маркеры или результат под ответ.
5. Требуется HTTP 200, непустой content, отсутствие усечения по лимиту и точное совпадение JSON с `expected.json`. Порядок ключей не важен. Все три значения обязательны. `/api/ps` должен показать context_length 262144. Пропуск хотя бы одного маркера даёт FAIL. Смена условий ADR-031 даёт REVALIDATE. Ошибка инструмента измерения даёт TEST_DEFECT и повтор только после исправления теста.
6. Предел ожидания одного прогона: 120 минут. При недоступности Ollama остановиться без перезапуска. Не отправлять повторный запрос, пока прежний не завершён. Не выполнять параллельно с рабочими задачами.

Точки вставки: после 100, 112350 и 224600 повторов. `expected.json` содержит точные ответы. SHA256 фиксирует весь JSON запроса, включая форматирование и завершающий LF.

Эксплуатационное доказательство Q6: `Этапы/2026-10-06_Qwen38_Q6_Pi_Complex_Bounded_Executor/Результаты.md`, LeaseFlow, автоматическое сжатие примерно на 93.8% окна. Это принятое доказательство сохраняется. Данная процедура проверяет другой сценарий и в RB-10 не исполнялась.
