# Результаты Этапа 7A: Continue.dev — Chat + Agent

**Дата:** 2026-03-16
**Сервер:** 192.168.0.128 (Ubuntu 22.04, RTX 3090 24 ГБ VRAM, 62 ГБ RAM)
**Шлюз:** ~/llm-gateway/gateway.py v0.7.0 (FastAPI + httpx → Ollama)
**Ollama:** http://localhost:11434, 9 моделей
**Клиент:** Windows 11, VS Code + Continue.dev v1.2.17

---

## Что сделано

### Continue.dev — базовая интеграция

Установлен Continue.dev v1.2.17. Создан config.yaml с тремя моделями, подключёнными к gateway.py через OpenAI-совместимый API. Chat mode (стриминг, reasoning) и Agent mode (function calling через tools) — работают.

### gateway.py v0.7.0 — проброс tool_calls

**Проблема:** Ollama возвращает tool_calls в `message.tool_calls`, но `stream_generator()` и `build_openai_response()` обрабатывали только `content` и `thinking`. Tool_calls терялись — Continue Agent mode получал пустой ответ.

**Решение:** Новая функция `convert_ollama_tool_calls_to_openai()` конвертирует формат Ollama в формат OpenAI:
- `arguments`: dict → JSON string
- `index`: из function на верхний уровень
- `type: "function"` добавляется
- `finish_reason: "tool_calls"` вместо `"stop"` при наличии tool_calls

Изменения в `build_openai_response()` (non-stream) и `stream_generator()` (stream): детекция tool_calls, конвертация, проброс через `message.tool_calls` / `delta.tool_calls`.

### Ollama systemd override — GGML_CUDA_NO_GRAPHS

Добавлен `GGML_CUDA_NO_GRAPHS=1` в `/etc/systemd/system/ollama.service.d/override.conf`. Без этого флага Agent mode вызывал CUDA graph capture crash (SIGABRT) при быстрой последовательности запросов.

Актуальный override:
```ini
[Service]
Environment="OLLAMA_FLASH_ATTENTION=1"
Environment="OLLAMA_KV_CACHE_TYPE=q8_0"
Environment="OLLAMA_MAX_LOADED_MODELS=1"
Environment="OLLAMA_HOST=0.0.0.0:11434"
Environment="CUDA_VISIBLE_DEVICES=0"
Environment="GGML_CUDA_NO_GRAPHS=1"
```

## Обнаруженные проблемы и решения

### 1. Таймаут Continue (КРИТИЧНО)

**Симптом:** Agent mode — каскад из 5+ запросов за 10 секунд, ни один не завершается, "Connection error".

**Причина:** Continue.dev v1.2.17 использует OpenAI Node.js SDK, который принимает `timeout` в **миллисекундах**. `timeout: 600` = 0.6 сек. За это время модель не успевала начать ответ.

**Решение:** `timeout: 600000` (10 минут в ms).

### 2. qwen3.5:35b не поддерживает function calling (КРИТИЧНО)

**Симптом:** Agent mode — модель возвращала мусорный текст на китайском вместо tool_calls. Даже с `think: false` генерировала `<think>` блоки.

**Причина:** qwen3.5:35b — thinking/reasoning модель. Не соблюдает протокол function calling, игнорирует tools в payload, уходит в бесконечные рассуждения.

**Решение:** Для Agent mode использовать **qwen3-coder:30b** — instruct/coder модель, которая корректно возвращает tool_calls (28 токенов, <1 сек).

### 3. tool_calls терялись в шлюзе (КРИТИЧНО)

**Симптом:** curl к Ollama напрямую — tool_calls есть. Через шлюз — пустой delta.

**Причина:** `stream_generator()` обрабатывал только `content` и `thinking` из чанков Ollama. Поле `tool_calls` игнорировалось.

**Решение:** gateway.py v0.7.0 — `convert_ollama_tool_calls_to_openai()` + проброс в stream и non-stream.

### 4. CUDA graph capture crash (СРЕДНЕ)

**Симптом:** Ollama падала (SIGABRT) при быстрой последовательности запросов в Agent mode.

**Причина:** CUDA graph capture несовместим с паттерном множественных быстрых запросов.

**Решение:** `GGML_CUDA_NO_GRAPHS=1` в Ollama override.

### 5. roles: agent невалидна (НИЗКО)

**Симптом:** Ошибка конфигурации Continue при указании `roles: [agent]`.

**Причина:** Continue 1.2.17 не признаёт `agent` как валидную роль. Agent mode использует ту модель, которая выбрана в UI.

**Решение:** Убрать `agent` из roles. Валидные roles: chat, edit, apply.

### Грабли Continue 1.2.17

- **YAML anchors** (`<<: *defaults`) — НЕ принимает, ошибка парсинга
- **Имена моделей со скобками/спецсимволами** — `"qwen3.5:35b (reasoning)"` вызывает `Invalid input`. Работают простые имена: `qwen35`
- **roles: agent** — невалидная роль, ошибка конфигурации
- **timeout** — в миллисекундах (OpenAI SDK), не в секундах. 600000 = 10 минут
- **version**: 0.0.1 и 1.0.0 — оба валидны
- Ошибки конфига: правый нижний угол VS Code «⚠ Continue (config error)» + DevTools Console фильтр `continuedev`
- Network tab DevTools не показывает запросы Continue (идут из extension host, не из webview)
- Команда «Continue: Open Config File» отсутствует, есть «Continue: Open Settings»

## Формат tool_calls Ollama (stream)

Ollama отдаёт tool_calls **одним чанком** целиком (не потоково):

```json
{"model":"qwen3-coder:30b","message":{"role":"assistant","content":"","tool_calls":[{"id":"call_izxn14pq","function":{"index":0,"name":"run_terminal_command","arguments":{"command":"ls -R"}}}]},"done":false}
{"model":"qwen3-coder:30b","message":{"role":"assistant","content":""},"done":true,...}
```

Шлюз конвертирует в формат OpenAI:

```
data: {"choices":[{"delta":{"role":"assistant"}}]}
data: {"choices":[{"delta":{"tool_calls":[{"index":0,"id":"call_izxn14pq","type":"function","function":{"name":"run_terminal_command","arguments":"{\"command\":\"ls -R\"}"}}]}}]}
data: {"choices":[{"delta":{},"finish_reason":"tool_calls"}],"usage":{...}}
data: [DONE]
```
